# Colaboraciones

Agradecemos incidencias centradas en traducción de menús, accesibilidad, documentación, fiabilidad y compatibilidad con la placa **Marauder v6.1/v6.2**.

Para informar un error de traducción, indicar el texto original, texto esperado, ruta de menú y una fotografía sin identificadores privados. Para un problema de actualización, indicar versión, SHA-256 y modelo exacto.

No publicar volcados de flash completos, credenciales, claves privadas ni capturas de tráfico que identifiquen redes o equipos ajenos. La edición no oficial no sustituye el soporte del firmware upstream.

Todas las aportaciones deben respetar la licencia MIT, los avisos de copyright originales y la atribución al proyecto **Just Call Me Koko**.
