# ESP32 Marauder v1.20.0 ES — Edición Española V4

**Publicación comunitaria no oficial.**  
**Autor original:** [Just Call Me Koko — ESP32 Marauder](https://github.com/justcallmekoko/ESP32Marauder).  
**Versión original:** [v1.20.0](https://github.com/justcallmekoko/ESP32Marauder/releases/tag/v1.20.0).  
**Adaptación al español y pruebas:** Fran Gonzas.

Esta edición modifica cadenas de texto visibles del binario oficial para **Marauder v6.1/v6.2 (ESP32 clásico)**, conservando su estructura y las funciones originales. Incluye cuatro revisiones V1–V4, con **V4 como versión recomendada**, y pantalla de inicio identificada.

**NO instalar en ESP32-C5, ESP32-S3 ni en ninguna placa que requiera un binario distinto.** Realizar copia de seguridad y tener disponible un procedimiento de recuperación antes de actualizar.
